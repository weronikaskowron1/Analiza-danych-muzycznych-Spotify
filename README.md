# Analiza danych muzycznych Spotify
Analiza danych top hitów Spotify (1998–2020) z wykresami i interaktywnymi wizualizacjami pokazującymi popularność artystów, cechy utworów i gatunki muzyczne.

## Technologie
- Python
- Pandas, NumPy
- Matplotlib, Seaborn, Bokeh

## Zakres prac
- Wczytanie i czyszczenie danych (duplikaty, brakujące wartości)
- Analiza statystyczna zmiennych numerycznych
- Wizualizacja danych (wykresy słupkowe, scatterploty, tabele, wykres kołowy, wykres interaktywny Bokeh)
